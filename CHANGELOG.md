# Changelog

## 1.1.0

- Add a camera button to the composer with a split menu.
- Add full-screen, region-crop, and window-picker capture modes.
- Hide the DSH window during capture and restore its placement.
- Attach only when the composer contains text; send immediately when empty.
- Add the local window-list route and `hwnd:` window selector.
- Add Chinese and English display metadata and documentation.

## 1.0.0

- Initial `screenshot` agent tool for full screen, region, and window capture.
- Save screenshots as conversation attachments and optional workspace files.
